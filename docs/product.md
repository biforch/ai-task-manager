# Product

## Project Name

AI Task Manager

---

## Project Goal

Build a simple task management application while practicing an AI-assisted software development workflow.

The project demonstrates the complete workflow:

- Product planning
- Architecture design
- Coding
- Testing
- Code review
- Git management
- Deployment preparation

---

## Target Users

Personal users who need a simple way to manage daily tasks.

---

## Core Problem

Users need a simple system to record, organize, and track tasks.

---

## MVP Features

### Task Management

Users can:

- Create tasks
- View task list
- Update task status
- Delete tasks

---

## Task Fields

Each task contains:

| Field | Description |
|-|-|
| id | Unique identifier |
| title | Task name |
| description | Task details |
| status | Todo / Doing / Done |
| createdAt | Creation time |
| updatedAt | Last update time |
