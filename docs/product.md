# Product

## Project Name

AI Workflow Lab


## Project Overview

AI Workflow Lab 是一个用于学习和实践 AI Coding 工作流的实验项目。

目标是建立一套完整的个人 AI 软件开发流程，让 AI 工具参与：

- 产品分析
- 技术规划
- 编码开发
- 测试验证
- 代码审查
- 项目管理


## Project Goal

建立一套稳定、可重复的 AI 开发工作流。

最终目标：

从一个想法开始，通过 AI 协助完成：

需求分析 → 产品设计 → 技术设计 → 编码 → 测试 → Review → Git 管理 → 发布


## AI Tool Roles

### ChatGPT

负责：

- 学习指导
- 需求分析
- 产品规划
- 架构讨论
- 问题分析


### Codex

负责：

- 阅读项目代码
- 编写代码
- 修改文件
- 执行测试
- 修复问题


### Claude

负责：

- 长文档分析
- 第二意见
- Code Review
- 架构检查


### Cursor

负责：

- IDE 编辑环境
- 查看代码
- 快速修改
- 调试


## Development Principles

1. 先理解，再修改。

2. 先计划，再执行。

3. 小步修改，持续验证。

4. 不提交任何秘密信息。

5. AI 负责执行，人负责最终决策。
